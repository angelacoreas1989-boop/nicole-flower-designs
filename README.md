# Nicole's Flower Designs 🌸

A luxury floral business website created for Nicole's Flower Designs.

This project was built to provide an elegant online presence for a family-owned floral business specializing in custom arrangements for weddings, quinceañeras, sweet 16 celebrations, memorial tributes, and seasonal décor.

## Live Website

https://angelacoreas1989-boop.github.io/nicole-flower-designs/

## Features

* Responsive mobile-friendly design
* Luxury floral-inspired user interface
* Photo gallery showcasing floral arrangements
* Request a Quote form
* Formspree integration for customer inquiries
* Custom services section
* Professional business branding
* GitHub Pages deployment

## Services Offered

* Wedding Centerpieces
* Quinceañera Arrangements
* Sweet 16 Floral Designs
* Memorial & Grave Flowers
* Seasonal Door Wreaths

## Technologies Used

* HTML5
* CSS3
* GitHub Pages
* Formspree
